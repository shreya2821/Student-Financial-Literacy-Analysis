# 📊 Student Financial Literacy Analysis

## Overview
This project analyzes students' financial literacy, spending behavior, budgeting habits, and awareness using Power BI.

## Tools Used
- Power BI
- Excel
- DAX
- Data Visualization

## Dashboard Pages

### 1️⃣ Overview Dashboard
- Total Respondents
- Savings Rate
- Budget Followers
- Financial Skill Rating
- Income Sources

### 2️⃣ Spending Analysis Dashboard
- Spending by Category
- Spending by Gender
- Spending by Age Group
- Highest and Lowest Spending Category

### 3️⃣ Financial Awareness & Behaviour Analysis
- Budget Management Habits
- Expense Tracking Methods
- Financial Literacy Support

### 4️⃣ Executive Summary & Recommendations
- Major Findings
- Strategic Recommendations
- Future Scope
- Conclusion

## Key Findings
- 62% of students save money, but only 26% actively follow a monthly budget.
- Parents and family are the major source of income.
- Accommodation is the highest spending category.
- Most students support financial literacy education.
